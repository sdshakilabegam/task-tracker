# Task Tracker

A small React app to add, complete and delete tasks.
Built in Week 4 of my web development internship at Sree Kavinya Technologies.

## Features

- Add a task (empty input shows an error message)
- Mark a task as complete (strikethrough) or undo it
- Delete a task
- Shows total tasks and how many are remaining

## Built with

React (Vite), JavaScript, CSS

## Concepts used

- useState for tasks, input text and error
- Controlled input and onSubmit with preventDefault
- Lists with map() and unique keys
- filter() for deleting and counting
- Props and callback functions (TaskItem component)
- Conditional rendering (error message, empty state)

## How to run

npm install
npm run dev
Then open http://localhost:5173
